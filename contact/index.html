Contact

Found a counting mistake, or have an idea for a tool? We would like to hear about it.

CountMyWords has no account system and no contact form, so the best way to reach us is through the public GitHub repository for this site:

github.com/datawithsaqib/countmywords

Please open an issue there with a short description of the problem or idea. If you are reporting a count that looks wrong, include the text you pasted (or a short example) and the number you expected — that makes it much easier to fix.

Please do not include passwords or private information in a public issue.
